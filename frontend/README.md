# 🏥 Pediatric Pneumonia AI Workstation — Frontend

> **Software & UI Design by Abdullah Ishaq**  
> **Copyright (c) 2026 Abdullah Ishaq. All rights reserved.**

A production-grade, responsive Next.js 14 web application designed for real-time radiological evaluation of pediatric chest X-rays.

---

## 🚀 Getting Started

First, install dependencies and run the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to launch the diagnostic workstation.

## 🔗 Backend API Integration

The frontend seamlessly connects to the PyTorch / FastAPI REST backend.
Configure the API endpoint in `.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```
